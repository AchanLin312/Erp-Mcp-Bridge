## 核心设计决策

### 决策 1：MCP 为 AI 唯一通道，内部委托 EpicorRestAPI

**MCP Tool 暴露执行能力，内部用 EpicorRestAPI 完成 HTTP 请求**。AI 不能直接调用 nuget 包，所有操作必须通过 MCP Tool：

- `CallBoMethod` / `CallEfxFunction`：将 EpicorRestAPI 的调用能力包装为 MCP Tool，供 AI 测试和验证
- 管理类 Tool（Push/Create/Delete Function）：内部也通过 EpicorRestAPI 调用 `EfxLibraryDesignerSvc` 的 BO 方法

**不是让 AI 绕过 MCP 直接用 EpicorRestAPI，而是 MCP 内部用 EpicorRestAPI，避免重复造轮子。**

### 决策 2：BO Service 发现 —— 纯文件系统，零反射

```
Assemblies 目录扫描:
  Erp.Contracts.BO.PartSvc.dll    →  Erp.BO.PartSvc
  Erp.Contracts.BO.SalesOrder.dll →  Erp.BO.SalesOrderSvc
  Ice.Contracts.BO.KineticErp.dll →  Ice.BO.KineticErpSvc
  ...
```

直接从文件名提取，毫秒级完成，无需加载 DLL 到内存。

### 决策 3：Swagger 按需解析

Epicor 的 `Tableset/DataSet` 嵌套结构极其复杂。例如 `PartSvc.GetByID` 返回的 `PartTableset` 嵌套 `PartRow`，包含 300+ 字段。全量返回会撑爆 AI 上下文。

**解法**：从 `swagger.json` 的 `paths` 定位目标方法，递归解析 `$ref` 指向的定义，提取核心业务字段，组装为精简 JSON 返回。

### 决策 4：EFX 管理 —— 基于 EfxLibraryDesignerSvc 的 TrackChanges 模式

Epicor 的 BO 方法遵循 TrackChanges 模式：
```
GetLibrary → 修改 Dataset → ApplyChanges
```

MCP 的 Push/Create/Delete Function Tool 内部封装这个流程，用户只需提供：
- Library ID + Function ID + C# 代码（Push）
- Library ID + Function ID + 代码 + 签名（Create）

## EFX Function 的数据库模型（参考）

| 表 (`Ecf` Schema) | 用途 | 关键字段 |
|---|---|---|
| `EfxLibrary` | Library 定义 | `LibraryID`, `Description`, `Mode`, `Published`, `Owner` |
| `EfxFunction` | Function 定义 | `LibraryID`, `FunctionID`, **`Body`** (JSON: `{"Code":"C# 源码..."}`), `Kind`, `Disabled` |
| `EfxFunctionSignature` | 参数签名 | `LibraryID`, `FunctionID`, `ArgumentName`, `DataType`, `Response`/`Input`, `Optional` |
| `EfxLibraryReference` | Library 引用的外部 DLL | `LibraryID`, `ReferenceType`, `ReferenceID` |
| `EfxLibraryMapping` | 公司映射 | `LibraryID`, `Company`, `Allowed` |
| `EfxLibraryLock` | 编辑锁 | `LibraryID`, `LockedBy`, `LockedOn` |

## EfxLibraryDesignerSvc 的 28 个 BO 方法（分类）

| 分类 | 方法 | 用途 |
|---|---|---|
| **Library CRUD** | `GetLibrary`, `GetLibraries`, `GetDefaults`, `ApplyChanges`, `ApplyChangesWithDiagnostics` | 获取/保存 Library |
| **Library 查询** | `GetLibraryList`, `GetLibraryList2`, `GetLibraryInfo` | 搜索/过滤 Library |
| **Function CRUD** | `GetFunctionList`, `GetFunctionList2`, `GetFunctionInfo`, `GetKineticFunction` | 查询 Function |
| **发布** | `PromoteToProduction`, `DemoteFromProduction`, `RegenerateLibrary`, `RegenerateAllLibraries` | 发布/编译 |
| **导入导出** | `ExportLibrary`, `ImportLibrary`, `InstallLibrary`, `UninstallLibrary` | 迁移 |
| **锁定** | `LockLibrary`, `ReleaseLibrary`, `ChangeOwner` | 并发控制 |
| **验证** | `IsValidLibraryId`, `IsValidFunctionId`, `IsValidFunctionParam`, `DetectCircularReferences`, `DetermineInstallationOrder` | 校验 |

## 技术栈

| 层 | 技术 |
|---|---|
| MCP Server SDK | `ModelContextProtocol` (C# SDK) |
| 运行时 | .NET 10 |
| HTTP 客户端 | EpicorRestAPI v3.0.2（底层用 RestSharp） |
| 传输 | stdio + HTTP/SSE |
| JSON 解析 | `System.Text.Json` / Newtonsoft.Json |
| 目标平台 | Windows（依赖 Assemblies 目录） |
